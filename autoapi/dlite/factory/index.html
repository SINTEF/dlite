dlite.factory#

A module that makes it easy to add dlite functionality to existing classes.

Class customisations#

In order to handle special cases, the following methods may be defined/overridden in the class that is to be extended:

`python _dlite_get_<name>(self, name) _dlite_set_<name>(self, name, value) _dlite__new__(cls, inst) `

class dlite.factory.BaseExtension(*args, instanceid=None, **kwargs)#

Base class for extension.

Except for dlite_id, all arguments are passed further to the __init__() function of the class we are inheriting from.

If instanceid is given, the id of the underlying dlite instance will be set to it.

Parameters:

instanceid (str)

classmethod _dlite__new__(inst=None)#

Class method returning a new uninitialised instance of the class that is extended.

This method simply returns cls.__new__(cls).

Override this method if the extended class already defines a __new__() method.

dlite.factory.objectfactory(obj, meta=None, deepcopy=False, cls=None, url=None, storage=None, id=None, instanceid=None)#

Returns an extended copy of obj.

The url, storage, and id arguments are passed to classfactory().

Parameters:

  • obj (Any) – A Python object.

  • meta (Optional[Metadata]) – A DLite Metadata Instance.

  • deepcopy (bool) – Whether to perform a deep copy. Otherwise a shallow copy is performed.

  • cls (Optional[type]) – A class to use for the new object. If this is not supplied, the new object will be of the same class as the original.

  • url (Optional[str]) – If given and meta is not given, load metadata from this URL. It should be of the form driver://location?options#id.

  • storage (Optional[Union[Storage, Tuple[str, str, str]]]) – If given and meta and url are not given, load metadata from this storage.

  • id (Optional[str]) – A unique ID referring to the metadata if storage is provided.

  • instanceid (Optional[str]) – A DLite ID (UUID) to use for the underlying DLite Instance.

Returns:

A new, extended copy of the Python object obj.

Return type:

Any

dlite.factory.classfactory(theclass, meta=None, url=None, storage=None, id=None)#

Factory function that returns a new class that inherits from both theclass and BaseExtension.

Parameters:

  • theclass (type) – The class to extend.

  • meta (Optional[Metadata]) – Metadata instance.

  • url (Optional[str]) – If given and meta is not given, load metadata from this URL. It should be of the form driver://location?options#id.

  • storage (Optional[Union[Storage, Tuple[str, str, str]]]) – If given and meta and url are not given, load metadata from this storage.

  • id (Optional[str]) – A unique ID referring to the metadata if storage is provided.

Returns:

A new class based on theclass and BaseExtensions.
