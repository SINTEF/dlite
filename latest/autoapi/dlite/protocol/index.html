dlite.protocol#

classmethod load_plugins()#

Load all protocol plugins.

The names of all plugin files that have been attempted to load are cached (regardless whether loading succeeded or not). Hence, it is safe to call this class method multiple times. It won’t reload already loaded plugins or try to reload plugins that already failed to load.

classmethod loaded_plugins()#

Return a set with the names of already loaded plugins.

classmethod failed_plugins()#

Return a set with the stem of the plugin files that have failed ot load. This is typically the same as the plugin names.

dlite.protocol.zip_compressions#
dlite.protocol.load_path(path, include=None, exclude=None, compression='lzma', compresslevel=None)#

Returns content of path as bytes.

If path is a directory, it will be zipped first.

Parameters:

  • path – File-like object or name to a regular file, directory or socket to load from .

  • include – Regular expression matching file names to be included when path is a directory.

  • exclude – Regular expression matching file names to be excluded when path is a directory. May exclude files included with include.

  • compression – Compression to use if path is a directory. Should be “none”, “deflated”, “bzip2” or “lzma”.

  • compresslevel – Integer compression level. For compresison “none” or “lzma”; no effect. For compresison “deflated”; 0 to 9 are valid. For compresison “bzip2”; 1 to 9 are valid.

Returns:

Bytes object with content of path.

dlite.protocol.save_path(data, path, overwrite=False, include=None, exclude=None)#

Save data to file path.

Parameters:

  • data – Bytes object to save.

  • path – File-like object or name to a regular file, directory or socket to save to.

  • overwrite – Whether to overwrite an existing path.

  • include – Regular expression matching file names to be included when path is a directory.

  • exclude – Regular expression matching file names to be excluded when path is a directory. May exclude files included with include.
