dlite.testutils.importcheck(module_name, package=None)#

Import and return the requested module or None if the module can’t be imported.

dlite.testutils.importskip(module_name, package=None, exitcode=44, env_exitcode='DLITE_IMPORTSKIP_EXITCODE')#

Import and return the requested module.

Calls sys.exit() with given exitcode if the module cannot be imported.

Parameters:

  • module_name – Name of module to try to import.

  • package – Optional package name that the module might reside in.

  • exitcode – The default exit code of sys.exit() if the module cannot be imported.

  • env_exitcode – Name of environment variable containing an exitcode to call sys.exit() with if the module cannot be imported. This overrides exitcode.

Notes

If you want to run the tests and get an error if a module cannot be imported, set environment variable DLITE_IMPORTSKIP_EXITCODE=1 before running the tests (if you run with ctest, set DLITE_IMPORTSKIP_EXITCODE at configure time).

For packages that depend on external services like postgresql, call importskip() with env_exitcode=None to skip the test regardless of whether DLITE_IMPORTSKIP_EXITCODE is set or not.

dlite.testutils.service_config(service)#

Return a dict with the configuration of the given test service.

Parameters:

service – Name of the service. Should be a key in TEST_SERVICES.

Returns:

Dict with the default configuration in TEST_SERVICES, where each value may be overridden by the environment variable DLITE_TEST_<SERVICE>_<KEY>.

dlite.testutils.service_available(service, timeout=2)#

Return true if the given test service can be contacted, otherwise false.

dlite.testutils.serviceskip(service, timeout=2, exitcode=44)#

Call sys.exit() with the given exit code if the given test service cannot be contacted. Otherwise return its configuration (see service_config()).

class dlite.testutils.skip_on_service_mismatch(service, exitcode=44)#

Context manager that calls sys.exit() with the given exit code if the code block raises an exception indicating that the server is not configured as expected (e.g. wrong credentials).

Example

with skip_on_service_mismatch(“postgresql”):

inst.save(f”postgresql://{location}?{options}”)
