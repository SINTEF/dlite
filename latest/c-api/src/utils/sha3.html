sha3#

Defines

SHA3_KECCAK_SPONGE_WORDS#

For documentation, see brainhub/SHA3IUF

The hashes generated with SHA3_FLAGS_NONE corresponds to sha3_256() sha3_384() and sha3_512() in Python hashlib.
